UXMC · Output Engine · System / Mega-menu Mega-menu · three variants, one shell
Same visual component, three behaviours per lens type. Jump-anchor (Lenses 1, 2, 3, 4, 5, 7, 8) · In-page filter (Lens 6) · Routed nav (Lens 9). Spec lives in MEGA_MENU.md.
1 · Jump-anchor Click smooth-scrolls to a section anchor on the current page. URL hash updates. No navigation. Used by 7 of 9 lenses.
2 · In-page filter Click filters the product grid in place. URL gets a ?category=… query param. No page reload. Shop only.
3 · Routed nav Click navigates to Template A or B (real URL). Standard browser nav. Lens 9 only.
