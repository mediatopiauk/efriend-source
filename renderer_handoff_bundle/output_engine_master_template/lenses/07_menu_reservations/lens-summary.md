# Lens 7 — Menu & Reservations

A hospitality-first surface for restaurants, pubs, cafés, gastropubs, hotels and takeaways — where the **menu is the page**, not a side surface. Sticky reservation bar → secondary nav → atmospheric hero → quick facts (cuisine / hours / dietary / phone) → full menu (priced, sectioned, allergen-flagged) → set menus & events → photo gallery → chef/story → reviews → find-us (map + hours + parking) → footer with the booking widget always one tap away.

Built around an in-page **booking flow** (party size + date + time + name + phone → DM/Stripe deposit) and a **menu-as-content-model** (sections → items with price + allergens + dietary flags). The "Sarah/Max" floating widget surfaces because hospitality runs on phone & last-minute changes. Covers ~300k UK businesses the other 6 lenses don't serve cleanly.
