# Lens 9 — Directory / Listings

For businesses where the page itself is a filterable browse-and-enquire surface — estate agents, holiday lets, used-vehicle dealers, recruitment agencies, member directories, plant-hire fleets, marina berth listings, art-fair exhibitor catalogues. Different from Shop (transactional) and Showcase Grid (curated portfolio): customers come to **browse many similar items and convert via enquire / book viewing / contact owner**.

Shape: utility bar → nav → hero with search bar → category strip with counts → filtered listings body (sidebar filters + cards + sort + map toggle + pagination) → featured listings band → why-us → reviews → list-with-us CTA → footer. Targets ~80k UK businesses where neither Shop nor Showcase fit cleanly — the listings business is its own design problem.
