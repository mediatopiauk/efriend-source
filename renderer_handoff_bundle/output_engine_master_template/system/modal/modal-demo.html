Dismiss affordances

  • ESC key — closes top-most modal (stack-aware)
  • Backdrop click — closes, except for forms with dirty state (confirm first)
  • Close button — always top-right of header, 36×36 hit target
  • Programmatic — window.UXMC.modal.close() for Claude Code wiring

Focus management (WCAG AA)

  • On open: focus first focusable element inside modal (input, or close X if none)
  • Tab cycles inside the modal only (focus trap)
  • On close: returns focus to the triggering element
  • aria-modal="true" + role="dialog" + aria-labelledby on every modal

Animation timing

  • Backdrop fade-in: 220ms · easing cubic-bezier(0.16, 1, 0.3, 1)
  • Modal scale 0.96→1 + fade-in: 220ms · same easing
  • Dismiss reverses at 160ms · cubic-bezier(0.4, 0, 1, 1)
  • Mobile sheet translate Y(100%→0): same timing curves
  • prefers-reduced-motion → drop scale, keep fade

Tokens (locked)

  • --m-bg · --m-text · --m-mute · --m-line
  • --m-radius: 12px · --m-shadow two-layer offset+ambient
  • --m-backdrop rgba dark + backdrop-filter: blur(6px)
  • --m-pad-x: 32 · --m-pad-y: 28 · --m-head-h: 64 · --m-foot-h: 76
  • Brand-driven: --brand-primary · --brand-cta · --brand-cta-text

Lens 8 · case studyWayfinding signage · Ironbridge Gorge Museums
case study hero · 21:9

The brief

Replace 24 wayfinding panels across 7 museum sites with weather-resistant signage that holds up to the Severn valley climate. Budget pressure: ~30% under previous supplier. Lead time: 8 weeks.

What we did

3mm Dibond aluminium composite, CNC-routed and UV-printed in our Bridgnorth workshop. Subsurface-mounted to existing posts using bespoke brackets we fabricated in-house. Each panel pre-positioned and dry-fit before final install.

The outcome

All 24 panels installed across two install weekends. 24-month UV warranty. Museum reports zero damage 14 months in despite a brutal winter.
